# TWIS PRO RIG — TRUE TARGET

Date: 2026-09-18
Status: governing product interpretation for the next music-engine pass

## What Randy has actually been asking for

This is not primarily a looper, beat pad, synth, DJ deck clone, or mobile DAW.

It is a **phone-first live electronic performance instrument** for a non-technical performer who wants to feel like they are standing behind a professional melodic-house / melodic-techno live rig.

The intended feeling is:

> Press PLAY and there is already a convincing piece of music happening. Touch one thing and something musical changes. Touch another and the room lifts, drops, breaks, breathes, or explodes. Randy should be performing music, not programming a sequencer.

## The hidden requirements that repeated requests were pointing at

1. **Immediate musicality**
   - PLAY must start a coherent track-like foundation, not isolated test tones.
   - The first 10 seconds must already feel intentional.

2. **Professional live-set behavior**
   - Layers are musical roles, not arbitrary sound generators.
   - Scenes reshape arrangement.
   - FX are transition/performance tools.
   - Controls are macro controls over many underlying parameters.

3. **Stupid-simple ownership**
   - Randy should not need music theory, synthesis vocabulary, routing knowledge, or DAW expertise.
   - The advanced machinery belongs underneath the interface.

4. **Phone-first reality**
   - Android Chrome is architecture, not a later compatibility check.
   - Silent on entry.
   - Audio starts only from deliberate user interaction.
   - Large touch targets.
   - No hidden precision gestures required for the core performance path.

5. **Professional sound before professional-looking controls**
   - A beautiful interface with browser-synth audio is failure.
   - Interaction proof is not sonic proof.

6. **Real performance arc**
   - Intro -> Deep -> Lift -> Break -> Build -> Drop/Peak -> Outro should feel like a set, not muting/unmuting rows.

7. **Texture and emotion**
   - Low-end movement.
   - Harmonic tension/release.
   - memorable melodic phrases.
   - atmosphere/air/ocean/room.
   - vocal fragments/textures.
   - transitions with anticipation and payoff.

8. **Freedom to play**
   - User can add/remove roles, switch scenes, mutate, catch loops, import their own audio, and perform without destroying the musical foundation.

## What it is NOT

- not a 16-pad toy;
- not a sequencer-first workflow;
- not a collection of oscillators;
- not a CDJ visual clone;
- not a DAW squeezed onto a phone;
- not a "professional" UI wrapped around amateur sound;
- not dependent on paid APIs or cloud generation for core performance.

## Governing test

If a normal person hears 30 seconds without seeing the screen, the sound should be recognizable as an intentional melodic electronic performance rather than a browser audio demo.

If that is false, the build is not ready no matter how many controls work.
